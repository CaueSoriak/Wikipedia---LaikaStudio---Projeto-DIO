# Projeto HTML e CSS — Semântica e Acessibilidade

## 📌 Sobre o projeto

Projeto desenvolvido como parte de um desafio prático, com o objetivo de aplicar conhecimentos básicos de HTML e CSS, trabalhando a estruturação de páginas web, a semântica do HTML e os princípios de acessibilidade.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização e apresentação visual das páginas.

## 🎯 Objetivos

- Praticar a estrutura básica de uma página web.
- Utilizar elementos semânticos do HTML5.
- Aplicar conceitos básicos de acessibilidade.
- Organizar e estilizar o conteúdo utilizando CSS.


## 📚 Aprendizados

Durante o desenvolvimento, foram praticados conceitos fundamentais de estruturação de páginas web, organização do código HTML, aplicação de estilos com CSS e utilização de elementos semânticos para melhorar a compreensão e a acessibilidade do conteúdo.
